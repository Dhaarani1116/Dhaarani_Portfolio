# Dhaarani M Portfolio

Personal portfolio website for Dhaarani M, built with Next.js, React, Tailwind CSS, and Framer Motion.

## Live Demo

Visit the deployed portfolio: https://dhaarani-portfolio.vercel.app/

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
